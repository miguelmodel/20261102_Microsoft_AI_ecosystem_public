# Microsoft AI Ecosystem presentation

**▶ View the slides: https://miguelmodel.github.io/20261102_Microsoft_AI_ecosystem_public/**

A 38-slide web presentation for a mixed no-code and pro-code customer audience
(about 36 minutes plus Q&A). It explains what it takes to use AI successfully,
using a car analogy, and maps that to Microsoft's AI ecosystem.

## What the deck covers

| Slides | Section |
|---|---|
| 1 | Opening |
| 2–6 | The evolution of agentic systems: from chatbots to coordinated agents, and how long agents can work on their own |
| 7–14 | Foundational principles through transportation: a car analogy (motor, chassis, GPS, wheels, steering wheel, fuel gauge, roads, stoplights, signs, toll checkpoint) mapped to AI |
| 15–24 | Nine production foundations: model, harness, prompts/instructions/skills, data grounding, tools/MCP/plugins, observability, infrastructure, orchestration, and the control plane for AI |
| 25–31 | Four complementary layers: Microsoft 365 Copilot (including Copilot Cowork), Copilot Studio, GitHub Copilot and Microsoft Foundry |
| 32–35 | The three IQs: Work IQ, Fabric IQ and Foundry IQ |
| 36–37 | Applying the layers: one person's journey across the tools, and how to choose a starting point |
| 38 | Q&A |

Start with familiar outcomes: catch up after a meeting, improve a draft, or explain spreadsheet findings.
App capabilities and entitlements differ; these examples are not a promise of identical support everywhere.

An app label alone does not establish a user's entitlement.

Copilot Chat is not universally web-only: supported Outlook experiences have bounded organizational grounding.
The broader licensed experience can use accessible work content, but neither grants unrestricted access to all company information.

Agent Builder is a guided way to configure a focused agent inside Microsoft 365 Copilot.
It may suit a knowledge task without a custom application; external-service actions call for a different authoring option.

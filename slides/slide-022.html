Control plane for AI

Who, or what, is acting?

Microsoft Entra

Identity and access for people and agents.

What data can it access and share?

Microsoft Purview

Data protection and compliance.

Is it being attacked or misbehaving?

Microsoft Defender

Threat protection for agents and their work.

Microsoft Agent 365

Visibility, governance and oversight across agents.

Limit allowed actions. Keep accountable ownership.

Controls enforce boundaries on access, data use, tools, and actions.
Governance supplies purpose, ownership, reviews, and lifecycle oversight.
Entra addresses identity/access, Purview data security/compliance, Defender threat protection, and Agent 365 oversight through complementary services.
This is not one switch, policy, or license that protects every agent identically.

Follow user → agent → tool → data/action and ask whose credentials and permissions apply at every connection.
Least privilege means granting only task-needed access.
A signed-in chat user does not settle all downstream authority.
The standard Studio event-trigger path uses maker credentials, and the Fabric tool's User/Maker choices differ.
An approval does not create missing authority, and a prompt instruction is not a permission boundary.
Keep traceable ownership, scoped actions, and a revocation/recovery path.
These responsibilities apply throughout operation, not only at a final checkpoint.
Now locate the product layers.

Technical reference, not spoken:
Entra Agent ID is GA, while agent-user targeting and agent risk are preview.
Conditional Access targets the actual token subject, and API-key access bypasses it.
Agent 365 Purview controls require documented sharing/policy scope, and new Agent 365 content does not inherit source labels.
Cowork has a separate matrix.
Defender's default real-time rule audits, not blocks, and blocking needs scoped rules.
Studio/Foundry runtime routes and detection/investigation have preview boundaries.
Agent 365 is Commercial GA from May 1, 2026, licensed per user.
Registry visibility includes unmanaged agents without its risk protection/observability.
Onboarding, policies, supported integrations, and gradual rollout still need checking.

Connect permitted work context.

Open available agents or enable Cowork plugins.

The starting point is familiar work, not a requirement to move every task into a new interface.
Copilot can assist inside supported Word, PowerPoint and Teams experiences.
Cowork adds delegated work around selected context and artifacts.
It can create or edit supported shared Office files, keeping selected edits at the same OneDrive or SharePoint location.
That continuity does not mean Cowork has an identical interface embedded in every app.

For an illustrative project update, prepare a Word briefing, review a PowerPoint presentation, and communicate through Teams.
Each component is documented, but that is not a tested unattended chain.
People still check outputs, recipients and approval choices.

Available Agent Store agents and enabled Cowork plugins offer explicit specialization routes.
A plugin may bundle skills, connectors, or both.
Opening an agent and enabling a plugin are different operations, not proof of arbitrary cross-agent delegation.
Next, consider when a team wants to tailor the business agent itself.

Technical reference, not spoken:
Grounding does not grant additional source access.
Account, entitlement, host, enabled extensions and connector sign-in determine support.
Cowork's own approval choices are session-scoped, with pre-authorized automated-task exceptions.
Do not apply a federated tool's persistent approval option to every plugin.
Shared-file editing is documented support, not independently established feature GA.
For newly created presentations, R05 names PowerPoint for the web rather than a universal desktop-open path.

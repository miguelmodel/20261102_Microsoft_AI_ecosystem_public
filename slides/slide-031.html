Use Microsoft Foundry as the current platform name.
Foundry can support a simple model-powered application without requiring an agent at all.

A prompt agent combines instructions, a supported model and tools, through visual or programmatic configuration.
A hosted agent runs customer code or a chosen framework on managed infrastructure.
Managed hosting does not remove responsibility for custom code, use-case testing or connected systems.

Custom AI can mean configuring behavior, selecting tools or implementing application logic, not training a new model.
Foundry is an option, not a prerequisite for every agent.

Studio and Foundry can both tailor business processes.
Studio emphasizes graphical low-code authoring, while Foundry offers visual prompt-agent configuration and greater custom runtime/application control.
For example, supported configured tools can contribute to an employee-onboarding process.
That is a capability illustration, not an unattended workflow guarantee.

Optional technical detail before the bridge:
The defined core experiences have GA evidence, while features such as monitoring and agent guardrails remain preview.
Do not recommend Foundry's preview declarative workflow designer as a durable new-development starting point.
Its documented retirement is December 1, 2026, separate from Studio workflows and Foundry prompt-agent configuration.

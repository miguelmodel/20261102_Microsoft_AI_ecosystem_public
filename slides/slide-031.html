Assistant or agent

Uses a signed-in user's permissions, not an app acting alone.

Understand relevant work and use appropriate tools.

Work IQ can bring meeting discussions, emails, and specification documents into a supported task.
It can also expose permitted operations, so it is not simply a read-only document connector.
The signed-in user's context is required; calling something an agent does not give it authority across the tenant.

Its core developer connections are generally available, but one remote tool for fetching grounding information remains public preview.
That is why availability must be checked for the specific capability.
Next, move from workplace context to shared business definitions.

Technical reference, not spoken:
Work IQ API family (A2A, remote MCP, REST): GA.
Remote MCP retrieve tool: public preview.
MCP is Model Context Protocol, used to connect tools and context.
APIs require delegated user authentication; application-only authentication is unsupported.

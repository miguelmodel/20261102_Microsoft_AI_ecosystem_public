AI model and agent observability

Evaluate

Did it perform the intended task?

Trace

Which model and tool calls occurred?

Monitor

How are quality, latency, cost, and failures changing?

Human ownership

Evaluation tests intended behavior, tracing records model and tool calls, and monitoring follows quality and operation over time.
Traces are execution evidence, not guaranteed visibility into every internal reasoning step.
Studio makers also have test chat, repeatable evaluations, and Monitor production metrics.
Test representative user access, denied requests, tool failures, and hostile instructions embedded in retrieved content.
A passing score is not a guarantee of correctness.
Assign an owner who can investigate or pause operation.
Next, examine the information supplied to the model.

Technical reference, not spoken:
Foundry core evaluation and prompt/hosted-agent tracing are GA, while monitoring and agent guardrails remain preview.
Individual evaluators and external/workflow tracing have separate preview labels.
Studio standard evaluation core is GA, while the GitHub Copilot harness Evaluate experience is production-ready preview.
Studio Monitor supplies documented production metrics, not a blanket GA assertion here.
Foundry agent guardrails do not automatically protect externally registered agents.
Captured prompts, outputs, and traces can be sensitive data and need governance.
Cowork Purview support is capability-specific.
Sensitive-prompt blocking is preview/rolling out, direct prompt-file uploads are not scanned by that control, and calendar invites are excluded from labeled-file/email coverage.

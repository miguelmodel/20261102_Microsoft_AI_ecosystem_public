Prompts, instructions and skills

Give agents clear direction and reusable know-how.

  • Prompts describe the task.
  • Instructions guide ongoing behavior.
  • Skills package reusable know-how.

Example: Agent Skills in .

Like a GPS, prompts, instructions and skills give the agent direction.
Prompts express a request, while agent instructions set a standing role, boundaries and response style.
Skills package task-specific instructions with optional scripts and resources, loaded when relevant in supported runtimes.
Microsoft Foundry documents versioned skills with its Microsoft Copilot harness in public preview, checked on 3 November 2026.
Copilot Studio and Microsoft 365 Copilot also document skills, with different authoring, runtime and availability boundaries.
Instructions do not grant service permissions, and scripts require review from trusted sources.

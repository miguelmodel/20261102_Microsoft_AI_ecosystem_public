An agent combines a model, instructions, context, and tools to work toward a task.
The chatbot is our answer-first illustration, not a claim that all chat interfaces lack tools.
Multiple agents can separate specializations, but add handoffs, state, cost, and failure modes.
The final stage zooms out to accountable system operation, not a fourth standardized Microsoft architecture class.

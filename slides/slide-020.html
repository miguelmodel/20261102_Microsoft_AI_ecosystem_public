Tools, MCP and plugins

Turn agent decisions into actions across connected systems.

  • Tools call functions and take actions.
  • MCP standardizes connections to tools and data.
  • Plugins and connectors package integrations.

Example: MCP servers in Microsoft Foundry.

The steering wheel represents how an agent acts on the world.
A tool can retrieve relevant knowledge or perform an action.
MCP standardizes connections to servers that expose tools and data.
Plugins package extensions, while connectors integrate specific services.
Choose appropriate tools, limit access, and require approvals for consequential actions.
Permissions and approval behavior vary by product.
